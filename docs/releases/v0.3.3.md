# Omen LCD control v0.3.3

Rings, Bars, Spotlight and Custom video / GIF / picture now share one main window. Selecting custom media switches the content in place, keeping the mode selector and tray/recovery controls available.

Playback FPS has its own label/input space in the media sidebar. The sidebar can scroll on smaller windows, and the input is checked for visibility at both default and minimum supported window sizes.

Existing settings, recovery backups and API tokens remain compatible. CPU temperature requires LibreHardwareMonitor, custom FPS requires a sender, and HP Image-mode dashboard refresh remains roughly 2 Hz.
