# Omen LCD control v0.3.1

Renames OMEN Screen to **Omen LCD control**, including the Windows executable, window titles, tray labels, project and release packages.

Includes the configurable Rings, Bars and Spotlight dashboards, six metric slots, GIF/video composition controls, tray operation, Windows/NVIDIA metrics, optional LibreHardwareMonitor sensors, and authenticated local custom data API from v0.3.0.

Existing settings, recovery backups and API token remain in `%LOCALAPPDATA%\OmenScreen` for compatibility. Exit the earlier version, extract the portable ZIP, and run `OmenLCDControl.exe`. API senders keep the same endpoint and token.

CPU temperature requires LibreHardwareMonitor. Game FPS requires an external data sender. HP Image-mode refresh limits dashboard animation to roughly 2 Hz. Physical display behavior needs verification on additional hardware. This unsigned community app has been tested on one OMEN MAX 45L configuration and is independent of HP.
