# Omen LCD control v0.3.2

All four display choices are now visible together: **Rings**, **Bars**, **Spotlight**, and **Custom video / GIF / picture**. Choose the fourth option to open the media editor, select your file, drag/zoom or use Fit/Fill, then click Apply to cooler screen. Return through Display modes to use stats again.

The GIF/video/picture feature was still present in the main editor; the stats window made it difficult to discover. This release adds the explicit fourth option and updates the editor button, README, screenshots and release packages. Selecting a mode does not change the cooler until you apply it.

Existing preferences, recovery backups and API tokens remain compatible. Close the previous version before running the new executable. CPU temperature requires LibreHardwareMonitor, custom FPS requires a sender, and HP Image-mode dashboard refresh remains roughly 2 Hz.
